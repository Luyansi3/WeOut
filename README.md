# WeOut 🎉

**WeOut** is a mobile social network app for events.
The app allows users to discover events through interactive maps, track live KPIs from attendees, and connect via profiles and social features.

---

## 🚀 Features

- 📍 **Event discovery** with interactive maps and filters  
- 📊 **Live KPIs** on event participation and engagement  
- 👤 **User profiles** with social features (friends, follow, etc.)  
- 📰 **Social feed** with posts and real-time event updates  
- 📅 **Event details page** with participant info and live statistics  

---

## 🛠️ Tech Stack

- **Frontend:** React Native, Expo, TypeScript, Tamagui  
- **State Management:** React hooks / context  
- **Navigation:** React Navigation  
- **Others:** ESLint, Prettier for code quality
